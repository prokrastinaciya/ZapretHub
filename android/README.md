# ZapretHub для Android

ZapretHub обрабатывает трафик на самом телефоне. Для DPI-режима приложению нужен доступ к Android VPN. Root и собственный сервер для него не требуются. Telegram может дополнительно подключаться к встроенному локальному MTProto-прокси.

## Установка и запуск

1. Скачайте подписанный APK из [Android-релиза на GitHub](https://github.com/prokrastinaciya/ZapretHub/releases/tag/android-v0.1.0). Сборка предназначена для Android 7.0 и новее на ARM64 (`arm64-v8a`).
2. Откройте ZapretHub, запустите DPI-обход и подтвердите запрос Android на VPN. Одновременно в профиле Android может работать один VPN-сервис.
3. Если целевой сайт не открылся, остановите DPI, откройте тест стратегий и примените профиль с лучшим результатом. Повторите проверку на мобильной сети, если там нужен другой профиль.
4. Для Telegram запустите TG WS Proxy и откройте ссылку подключения из приложения. Доступность маршрутов прокси зависит от сети и его настроек.

APK обрабатывает трафик приложений на телефоне. Пресеты Android предназначены для ByeByeDPI. Для импорта доменов из Windows откройте настройки DPI, выберите «Импортировать списки из Windows (.zhub)» и укажите архив Zapret Hub. Импортируются пользовательские списки доменов, которые затем можно подключить в редакторе Android-стратегий. Пресеты `.bat`, наборы IP, сетевые профили Windows и настройки Telegram из архива не импортируются.

Автоматическое переключение по состоянию сети и раздача Telegram-прокси по локальной сети пока отсутствуют. Подбор стратегий проверяет HTTPS-доступность своих целей. Голос Discord, мобильные игры и покрытие у конкретного оператора требуют проверки на телефоне.

## Сборка

Нужны JDK 21, Python 3.13, Android SDK API 35, Build Tools 36.0.0, NDK 28.2.13676358 и CMake 3.22.1.

```sh
cd android
sdkmanager 'platforms;android-35' 'build-tools;36.0.0' 'ndk;28.2.13676358' 'cmake;3.22.1'
./gradlew :dpi-runtime:testDebugUnitTest :app:testArm64DebugUnitTest :app:assembleArm64Release
```

Без настроенного ключа release-задача создаёт неподписанный APK в `app/build/outputs/apk/arm64/release/`. Для локальной разработки установочный APK создаёт задача `:app:assembleArm64Debug`. Сборку для x86_64-эмулятора создаёт `:app:assembleEmulatorDebug`.
