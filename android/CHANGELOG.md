# ZapretHub Android

## 0.1.1

- Подбор стратегий проверяет видеоузлы YouTube, CDN и шлюз Discord и показывает задержку.
- Среди стратегий с полным покрытием сравниваются до трёх вариантов.
- В режиме VPN можно отключить UDP/443 для перехода с QUIC на HTTPS через TCP.

## 0.1.0

- Первый предварительный выпуск ZapretHub для Android.
- Локальный VPN и SOCKS5 для обхода DPI, подбор совместимой стратегии и выбор приложений для VPN.
- Локальный MTProto-прокси для Telegram на базе Flowseal.
- Импорт пользовательских доменных списков из архивов `.zhub` для Windows.
