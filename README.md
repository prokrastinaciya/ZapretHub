# Zapret Hub

Локальный менеджер для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Один файл `ZapretHub.exe`, без серверов: всё скачивается напрямую с GitHub.

**Стек:** C# / .NET Framework 4.8 (встроен в Windows 10/11) + WebView2 (интерфейс на HTML/CSS). Библиотеки WebView2 вшиты в exe.

## Возможности
- **zapret:** запуск стратегии вручную или установка службой Windows; Game Filter, IPSet (loaded/none/any), замена активных фейков, редактор списков доменов и IP, обновление ipset-списка и hosts.
- **Редактор стратегий:** набор аргументов winws собирается в форме (блоки фильтров, метод обхода, fooling, фейки) и сохраняется как `custom (…).bat`. Свои стратегии переживают обновление zapret.
- **Поиск ALT:** порт `utils/test zapret.ps1` — стандартный тест (HTTP/TLS1.2/TLS1.3 + ping + голос Discord по UDP), тест DPI 16–20 КБ и проверка своего сайта; рейтинг стратегий, запуск лучшей в один клик. Свежие стратегии из ветки `main` можно загрузить ещё до релиза.
- **Автоматика:** фоновая проверка Discord, YouTube и голоса Discord; самовосстановление (если связь пропала, приложение проверяет лучшие стратегии и переключается на рабочую); своя стратегия для каждой сети с автоматическим переключением.
- **История:** график доступности по времени с активной стратегией, сбоями и переключениями.
- **TG WS Proxy:** установка, запуск и остановка, редактор конфига, ссылка `tg://proxy` и кнопка «Подключить Telegram», проверка DC, журнал. **Раздача по Wi-Fi:** QR-код для телефона, правило брандмауэра только для локальной подсети, список подключённых устройств.
- **Диагностика:** все проверки из `service.bat` (BFE, прокси, TCP timestamps, Adguard, Killer, Intel, Check Point, SmartByte, VPN, DoH, hosts, WinDivert, конфликтующие обходы) с кнопками исправления и «Исправить всё»; очистка кэша Discord.
- **Обновления:** проверка и установка zapret, TG WS Proxy и самого Zapret Hub; пользовательские списки и настройки сохраняются. Можно включить автоустановку.
- Трей с быстрым переключением стратегий, глобальная горячая клавиша вкл/выкл обхода (по умолчанию Ctrl+Alt+Z), автозапуск через Планировщик задач (без запроса UAC), уведомления.
- Экспорт и импорт настроек (`.zhub`), архив для баг-репорта в один клик.
- Русский и английский интерфейс.

## Установка
Один и тот же `ZapretHub.exe` работает и как portable, и как установщик: кнопка «Установить в систему» в настройках копирует его в `C:\Program Files\Zapret Hub`, создаёт ярлыки в «Пуске» и на рабочем столе и регистрирует деинсталлятор в «Параметры → Приложения». Копия с `Setup` в имени файла (`ZapretHub-Setup.exe`) сразу предлагает установку.

## Сборка
```
dotnet build -c Release
```
Результат: `bin/Release/net48/ZapretHub.exe`. Для запуска нужны права администратора (их требуют winws/WinDivert).

## Где лежат данные
- Утилиты по умолчанию: `C:\ZapretHub\zapret`, `C:\ZapretHub\tg-ws-proxy` (меняются в настройках). Если zapret уже установлен, приложение найдёт его по службе или по запущенному winws.exe.
- Настройки, журналы, история проверок и профиль WebView2: `%LOCALAPPDATA%\ZapretHub`.
- TgWsProxy работает в портативном режиме (`TgWsProxy_data` рядом с exe). Если конфиг уже есть в `%APPDATA%\TgWsProxy`, он импортируется.
